# Мини-визитка GT Marketing and Tourism

Одностраничная визитка компании: контакты, реквизиты, лицензия и свидетельство
о госрегистрации. Открывается по QR-коду с телефона.

```
gt-card/
├── index.html            ← готовая страница, один файл, ~1,5 МБ
├── card.template.html    ← исходник (без встроенных картинок)
├── build.py              ← собирает index.html из шаблона
├── qr_assets.py          ← генерирует QR-материалы под печать
└── print/
    ├── qr-card.png       ← карточка A6 (105×148 мм, 300 dpi) для стойки
    ├── qr.png            ← только QR-код, 880×880
    ├── qr.svg            ← только QR-код, вектор (для любого размера)
    └── qr-card.html      ← исходник карточки A6
```

## Что внутри страницы

- Шапка с эмблемой и статусом лицензии
- Быстрые действия: звонок, Telegram, e-mail, сайт
- Документы — лицензия и свидетельство, открываются во весь экран
  с увеличением и кнопкой «Скачать»
- Реквизиты компании — нажатие на строку копирует значение
- Банковские реквизиты «Kapital 24» с вкладками UZS / USD / EUR / RUB
  и кнопкой «Скопировать все реквизиты»
- Два QR-кода: визитка директора (сохраняется в адресную книгу)
  и переход на incoming.uz
- Переключатель RU / UZ / EN — язык подхватывается из настроек браузера

Все данные взяты из трёх официальных документов: лицензии № 749920,
свидетельства о госрегистрации № 2805487 и карточки реквизитов.
Банк — «Kapital 24», филиал розничного бизнеса Капиталбанка,
МФО 01158, SWIFT KACHUZ22.

## Где разместить

`index.html` самодостаточен: шрифты подгружаются с Google Fonts, всё остальное
(логотип, изображения документов, оба PDF) встроено в файл. Никакой сборки
на сервере не нужно.

Положите файл на свой домен, например `https://incoming.uz/card/index.html`,
и перегенерируйте QR под этот адрес:

```bash
python3 qr_assets.py "https://incoming.uz/card/"
```

Скрипт перезапишет `print/qr.svg`, `print/qr.png` и `print/qr-card.png`.

## Пересборка страницы

Правки вносятся в `card.template.html` (тексты и данные — в блоке `<script>`
вверху: `T` — надписи интерфейса, `COMPANY`, `LIC_FACTS`, `LIC_KINDS`,
`BANK_NAME` и `ACCOUNTS`; у каждого поля три языка `ru` / `uz` / `en`), затем:

```bash
python3 build.py
```

`build.py` подставляет в шаблон логотип, изображения документов, оба PDF
и два QR-кода — vCard директора и ссылку на incoming.uz.

QR-коды в странице обязаны иметь `shape-rendering:crispEdges` — без него
браузер сглаживает модули и камера перестаёт их читать.

Зависимости: `pillow`, `qrcode`, `pypdf`, `pypdfium2`.

## Печать

`print/qr-card.png` — 1240×1748 px, это ровно A6 при 300 dpi. Годится и как
настольная табличка на стойке, и как оборот визитки (тогда обрежьте до нужного
формата — QR останется читаемым до ~2 см в стороне).
