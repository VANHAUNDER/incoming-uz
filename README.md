# Мини-визитка GT Marketing and Tourism

Одностраничная визитка компании: контакты, реквизиты, лицензия и свидетельство
о госрегистрации. Открывается по QR-коду с телефона.

**Адрес:** https://vanhaunder.github.io/incoming-uz/

```
├── index.html            ← собранная страница, один файл, ~1,5 МБ
├── card.template.html    ← исходник: вёрстка, тексты, данные
├── assets/               ← логотип, изображения документов, оба PDF
├── build.py              ← собирает index.html из шаблона и assets/
├── qr_assets.py          ← генерирует QR-материалы под печать
└── print/
    ├── qr-card.png       ← карточка A6 (105×148 мм, 300 dpi) для стойки
    ├── qr.png            ← только QR-код, 688×688
    ├── qr.svg            ← только QR-код, вектор (для любого размера)
    └── qr-card.html      ← исходник карточки A6
```

## Что внутри страницы

- Шапка с эмблемой на фирменной ленте
- Быстрые действия: звонок, Telegram, e-mail, сайт
- «Сохранить контакт» — скачивает `.vcf`, телефон открывает его как готовый контакт
- Документы — лицензия и свидетельство, открываются во весь экран
  с увеличением и кнопкой «Скачать»
- Реквизиты компании — нажатие на строку копирует значение
- Банковские реквизиты с вкладками UZS / USD / EUR / RUB
  и кнопкой «Скопировать все реквизиты»
- Переключатель RU / UZ / EN — язык подхватывается из настроек браузера

Все данные взяты из трёх официальных документов: лицензии № 749920,
свидетельства о госрегистрации № 2805487 и карточки реквизитов.
Банк — «Kapital 24», филиал розничного бизнеса Капиталбанка,
МФО 01158, SWIFT KACHUZ22.

## Как обновить

Правки вносятся в `card.template.html`. Тексты и данные лежат в блоке
`<script>`: `T` — надписи интерфейса, `COMPANY`, `LIC_FACTS`, `LIC_KINDS`,
`BANK_NAME`, `ACCOUNTS`, `DOCS`. У каждого поля три языка — `ru`, `uz`, `en`.

```bash
python3 build.py
git commit -am "правка реквизитов" && git push
```

GitHub Pages пересобирает сайт сам, обычно за минуту.

`index.html` самодостаточен: шрифты подгружаются с Google Fonts, всё остальное
(логотип, изображения документов, оба PDF) встроено в файл. Его можно просто
скопировать на любой другой хостинг — например на `incoming.uz` — сборка
на сервере не нужна.

Зависимости для сборки: `qrcode` (нужен только для `qr_assets.py`).

## QR-коды

Если адрес страницы поменяется, перегенерируйте коды под него:

```bash
python3 qr_assets.py "https://incoming.uz/card/"
```

Скрипт перезапишет `print/qr.svg`, `print/qr.png` и `print/qr-card.png`.
Карточка A6 рендерится установленным Google Chrome, чтобы подхватились
те же шрифты, что и на странице.

QR-коды обязаны рисоваться с `shape-rendering: crispEdges` — без него браузер
сглаживает края модулей и камера перестаёт читать код.

## Печать

`print/qr-card.png` — 1240×1748 px, это ровно A6 при 300 dpi. Годится и как
настольная табличка на стойке, и как оборот визитки (тогда обрежьте до нужного
формата — QR останется читаемым до ~2 см в стороне).
